# MoMo 的云端伙伴

住在平板里的 AI 伙伴，陪 8 岁的沫沫（MoMo）自己管好每一天：

- **记得课程表**：学校按 D1–D6 轮换，问"明天上什么课""下周一呢"，伙伴按课表回答，不会编造。
- **场景跟着任务走**：到了写作业、阅读的时间，画面换到书房；练琴换到琴房；运动换到运动馆或公园；洗漱、整理书包回卧室；没有事的时候在庭院（沫沫可以换成云海或原来的彩色背景），睡觉时间是卧室的夜晚。晚上 7 点以后每个场景都换成夜景。沫沫点一下任务选「现在开始」，或者跟伙伴说"我开始写作业了"，也会马上换过去。妈妈的页面能看到同一个场景，顶上写着沫沫在哪儿做什么。
- **伙伴主动开口**：不用等沫沫点，伙伴会跟着任务主动说话——任务前 5 分钟让她先准备，到点邀请她开始（写作业时还会问先做哪一件），一刻钟还没开始就轻轻提一句，做的过程中提醒坐直、看看远处、喝口水、手腕放松，时间到了问做完没有，做完夸她并说下一件是什么；早上说今天的课和要带的东西，下午空闲时偶尔提醒还没做的作业，睡前一刻钟提醒整理书包、刷牙洗脸。每句话都由伙伴自己的模型根据当时的情况说出来，说话方式跟她的性格一样；沫沫正在说话时伙伴会等她说完，安静时间不出声，平板没开就不说。
- **好感度进化**：任务做完、妈妈确认后才涨好感度，宠物随之进化（比如小九的尾巴从 1 条长到 9 条）。
- **说话就能用**：问课程、说"作业写完了"、"明天七点叫我起床"都行按一下说话，说完停一下伙伴就会回答；回答完她会接着听几秒（连续对话，按钮上写着「还在听…」），接着说就能一直聊下去，不说就停，不用每句都再点一次。最多连着听 5 轮（防止开着电视时一直被电视引着说话）；安静时间不接着听；妈妈可以在「管理 → 伙伴」里关掉。
- **喊名字就能说话（语音唤醒）**：沫沫的平板开着时，喊当前伙伴的名字（星灯、云笈、彩练、芯芯），比如"云笈，明天上什么课？"，她马上就听，不用点；只喊"云笈"，她会说"我在！"再等沫沫说。名字是平板自己听的（开源的 sherpa-onnx 唤醒词模型在平板上运行），听到名字之前声音不会离开平板；听到以后，这一句才发去识别，服务器还会核对确实叫了她（电视里说到像她名字的词，她不会乱接话）。屏幕顶上一直显示「👂 喊「云笈」」；她说话、在听的时候不听名字；安静时间和页面不在前台时麦克风关掉。妈妈可以在「管理 → 伙伴」里关掉。第一次打开要下载约 10 MB（之后缓存一周）。
- **8 个伙伴自由搭配**：4 个少女（星灯、云笈、彩练、芯芯）负责说话，4 个宠物（糖糖、团团、小九、青青）负责陪伴和进化。
- **会动、有表情**：少女全身站在画面中间，是两段循环动画：安静站着时轻轻呼吸、眨眼、头发飘动，说话时边说边做小手势，声音一停就回到安静的样子；想事情、开心、欢呼、担心、犯困各有一个姿势。
- **宠物有自己的生活**：平时绕着少女走来走去（四条腿真的在迈步，踩着祥云的形态是飘着走），会绕她跑一圈（从她身后穿过去）、躲到她背后再从腿边探出头、蹦跳、东张西望，一阵子没人理就打个盹，晚上睡在她脚边。沫沫说话时它跑到前面听，少女想事情时它在旁边歪着头，少女说话时它凑过来仰头听，有好消息一起跳；点它会跳起来，连点三下少女会说说它，点少女它也会跑过去。
- **拍照给伙伴看**：沫沫和妈妈都能拍照或发截图。课程表会自动更新到课表里；老师发的作业清单会自动加到今天的任务；一页作业题，伙伴会一步一步引导沫沫想，不直接给答案。
- **一起看着作业和文件学**：沫沫发来一页作业，它马上在伙伴旁边打开，每道题用虚线框出来、标上题号。沫沫问"第三题怎么做"，第三题就亮起来；沫沫用手指点纸上任何一处，伙伴会说"这是……"并把她说的地方圈出来（作业题照样只引导、不给答案）；伙伴自己讲到哪里，也会把那里圈亮。Word、PPT、Excel、PDF 都一页一页画成图片在这里看，能翻页、放大，图片也一样能点。妈妈的页面也能这样看文件、点着问。
- **发文件给伙伴读**：任何文件都能发，不限格式和大小（单个最大 2 GB），都存在自己的服务器上，不会自动删除。伙伴能读的：Word、Excel、PPT、PDF（扫描的也行，最多 200 页）、电子书（EPUB）、网页、各种文本；老的 doc、xls、ppt、WPS 和 OpenDocument 文件也行。音频、视频、压缩包这些先存着。伙伴读完先说个大概和里面的日子（很长的文件她会一段一段读完，读得久的先回一句"存好了，读完告诉你"）；之后妈妈可以问"运动会那天要带什么""沫沫哪科最弱""总结一下这个课件"，伙伴翻原文回答，能说出在第几页、哪张表。文件里是课程表或作业清单的，跟照片一样自动更新课表、加任务。
- **伙伴自己翻文件**：所有存着的文件伙伴都能自己找来读。妈妈问"上个月那个家长会通知说了什么"，她会在所有文件里搜，找到再读；沫沫问"我发给你的故事里小狐狸叫什么"，她也会去沫沫的文件里找。妈妈页面左边的「文件」里能看到所有文件，按名字或内容搜，打开、保存原文件、删除，或者让伙伴再读一次。
- **沫沫的页面**：左边一列小圆按钮（和右下角的上传、打字按钮一个样子）：今天要做的事、图书馆、好感度，以后的功能也加在这里。平时伙伴右边是空的，点哪个按钮，它的内容就在右边打开（手机竖着拿时盖在下半部分），再点一下或点 ✕ 就收起来。
- **沫沫的图书馆**：她发过的文件和妈妈发给她的文件，妈妈新发来的带红点，伙伴也会说一声"妈妈给你发来了《……》"。照片和文件的每一页直接在右边看（可以点着问，见上），音乐和视频直接播放，还能看到伙伴读出来的大意、要点、日子和原文，点「讲给我听」伙伴就讲这个文件。
- **妈妈也有伙伴**：妈妈的页面和沫沫的一样，是同一个伙伴，可以说话或打字问她"沫沫作业写完了吗"，让她"告诉沫沫七点前练琴"；沫沫说"帮我告诉妈妈…"，妈妈那边也会马上听到。左边也是一列按钮：动态、今天的任务（点一下就能确认）、刚才说的、看看沫沫、文件、管理；右边平时显示今天的动态和照片，点哪个按钮就换成哪个。
- **看看沫沫**：妈妈点「在做什么」「在练琴吗」「看看坐姿」，平板会先说一声、角落里显示摄像头画面，然后拍一张照片（练琴还会听几秒声音），伙伴把看到的告诉妈妈；坐姿不对，还会温柔地提醒沫沫。
- **推送到妈妈手机**（可选）：妈妈的页面没打开时，沫沫让转告的话、「看看沫沫」的结果、做完等确认的任务，会推送到妈妈的微信（或别的推送服务）。

## 用到的服务

| 用途 | 服务 |
|---|---|
| 判断要做什么（查课表、记完成、定闹钟） | 火山方舟 `doubao-seed-2-1-lite` |
| 伙伴说话 | 火山方舟 `doubao-seed-character` |
| 听懂沫沫说的话 | 豆包「录音文件识别极速版」（开通了就用，最快）；没开通时用火山方舟 `doubao-seed-2-0-mini` |
| 伙伴的声音 | 豆包语音 2.0（没配置时用平板自带的声音） |
| 看照片、扫描件和平板拍的照片；读文件、做总结 | 火山方舟 `doubao-seed-2-1-pro` |
| 和妈妈对话 | 火山方舟 `doubao-seed-2-1-lite` |

服务器只需要 Node.js（22.13 以上），不用装任何 npm 包；数据存在一个 SQLite 文件里。读 PDF 用到 poppler，读 doc、xls、ppt 这些旧格式用到 LibreOffice（安装脚本都会自动装）。

## 第一次部署（火山引擎 Ubuntu 24.04）

以下命令都在 ECS Terminal 里，用 root 运行。

**1. 装 Node.js、git、Caddy**（装过就跳过）

```bash
export DEBIAN_FRONTEND=noninteractive NEEDRESTART_MODE=a
apt-get update -y && apt-get install -y git curl gnupg debian-keyring debian-archive-keyring apt-transport-https
curl -fsSL https://deb.nodesource.com/setup_24.x | bash - && apt-get install -y nodejs
curl -1sLf https://dl.cloudsmith.io/public/caddy/stable/gpg.key | gpg --batch --yes --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
curl -1sLf https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt > /etc/apt/sources.list.d/caddy-stable.list
chmod o+r /usr/share/keyrings/caddy-stable-archive-keyring.gpg /etc/apt/sources.list.d/caddy-stable.list
apt-get update -y && apt-get install -y caddy
```

**2. 拉代码**

```bash
git clone https://github.com/willamxu881201-beep/momo-companion /opt/momo-companion
```

仓库如果设成了私有，需要先给服务器一个只读的部署密钥，见文末「私有仓库」。

**3. 运行安装脚本**（把域名换成你的；没有域名就用 `IP 用横线连接.sslip.io`）

```bash
bash /opt/momo-companion/deploy/install.sh 101-47-157-111.sslip.io
```

**4. 填密码和 Key**

```bash
nano /etc/momo/momo.env
```

填好 `PARENT_PASSWORD`（家长后台密码）、`ARK_API_KEY`，有豆包语音就填 `DOUBAO_APPID` 和 `DOUBAO_TOKEN`。按 `Ctrl+O` 回车保存，`Ctrl+X` 退出，然后：

```bash
systemctl restart momo
```

这个文件只有 root 能读，密钥不会出现在代码和网页里。

**5. 打开妈妈的页面** `https://你的域名/parent`，用家长密码登录，点「管理」：

1. **课表**：填"某一天是 D 几"、每个 D 的课程、假期。也可以直接把课程表拍照或者把文件发给伙伴（点向上箭头的上传按钮），她会自动填好。
2. **每天的任务**：添加每天的事（写作业 16:00、练琴 17:00……）。「在哪儿做」默认按任务名自动判断场景，也可以指定。只做一次的事直接跟伙伴说，老师的作业清单拍照发给她就行。
3. **平板**：复制「孩子页面的链接」，在平板或手机上打开。几台设备都能用同一个链接；链接里带着一把钥匙，不要发到群里，万一发出去了就点「换一个新链接」，旧链接马上失效。

**6. 平板上**：打开孩子页面的链接，点「叫醒伙伴」。打开过一次以后，这台设备直接打开 `https://你的域名/` 也能进。建议：
- 用 Chrome 打开，菜单里「添加到主屏幕」，以后像 App 一样全屏打开。
- 第一次说话时允许使用麦克风；妈妈第一次要「看看沫沫」时，平板会问能不能用摄像头，点允许。
- 平板接上充电，页面开着就会到点提醒。

## 手机推送（可选）

妈妈的页面没打开时，伙伴可以把这些推送到手机：沫沫让伙伴转告的话、「看看沫沫」的结果、沫沫说做完了的任务（等你确认）、沫沫发来的照片和文件（只推一句话，不推照片和文件本身）。几件事挨得很近会合成一条；页面开着时不推，因为页面上伙伴已经说了。

选一个推送服务，拿到它给你的地址，在服务器上加到 `/etc/momo/momo.env` 里：

```bash
nano /etc/momo/momo.env
# 加一行，比如：
# NOTIFY_URL=https://wxpusher.zjiecode.com/api/send/message/SPT_你的SPT
systemctl restart momo
```

然后在妈妈页面点「管理 → 平板 → 发一条测试推送」，看手机收到没有。

| 服务 | 推到哪里 | `NOTIFY_URL` 怎么写 |
|---|---|---|
| WxPusher 极简推送 | 微信 | `https://wxpusher.zjiecode.com/api/send/message/SPT_你的SPT`（在 WxPusher 文档的「极简推送」里用微信扫码拿到 SPT） |
| Server酱 | 微信 | `https://sctapi.ftqq.com/你的SendKey.send`（免费版每天只能推几条） |
| PushPlus | 微信 | `https://www.pushplus.plus/send?token=你的token` |
| 企业微信、钉钉、飞书的群机器人 | 群聊 | 机器人的 Webhook 地址原样填（钉钉的安全设置选「IP 地址」，填服务器的 IP） |
| Bark | iPhone | `https://api.day.app/你的key` |
| ntfy | ntfy App（安卓、iPhone） | `https://ntfy.sh/你起的频道名`（名字起长一点，别人猜不到） |
| Telegram | Telegram | `https://api.telegram.org/bot机器人的token/sendMessage?chat_id=你的ID` |

- 想少收一些：`NOTIFY_KINDS=message,check`（`message` 沫沫的留言，`check` 看看沫沫的结果，`done` 做完的任务，`photo` 沫沫发来的照片和文件；不填就是全部）。
- 每天最多推 30 条，`NOTIFY_PER_DAY` 可以改。
- 这个地址里带着你在推送服务的密钥，和其他 Key 一样只填在服务器上，不要发给别人。推送的那一两句话会经过你选的服务。


## 好感度规则

| 怎么得到 | 加多少 |
|---|---|
| 妈妈确认一件任务完成 | +10 |
| 这件任务是按计划时间做完的 | 再 +5 |
| 早上（5:00–10:00）或晚上（19:00–22:30）第一次和伙伴说话 | +3 |
| 聊天 | 每次 +1，每天最多 +5 |

好感度只涨不跌，换伙伴也不清零。宠物在 300、1000、2500 点时进化到第 2、3、4 阶段。

妈妈在后台确认任务后，平板上的伙伴会马上夸沫沫，并说出加了多少好感度；宠物进化时会发光，伙伴会宣布它的新样子。

## 隐私和费用

- 不保存录音；聊天记录只在内存里留 20 分钟，用来接上下文，不写进数据库。妈妈问起时，伙伴只知道沫沫做了什么事（任务、照片、传的话），不知道聊天的原话。
- 发给伙伴的照片和文件只存在自己的服务器上，一直保留，直到妈妈在页面左边的「文件」里删除；平板「看看沫沫」拍的照片 7 天后自动删除。都只有登录了家长密码，或者在沫沫的页面上才能看：沫沫的页面只看得到她自己发的，和妈妈给她看的。妈妈发的文件默认给沫沫看（她的图书馆里能打开，也能问伙伴）；看起来是妈妈自己的（工作文件、账单、合同、证件、病历这类，还有压缩包等平板上打不开的）只给妈妈，每个文件都可以在卡片上改。沫沫发的文件，妈妈也能看到、能问。文件的文字会发给火山方舟的模型去读，和聊天一样；在页面上点着问的时候，那一页的图片也会发过去。平板拍照前伙伴会先说一声，拍照时屏幕角上一直显示摄像头画面，不会偷偷拍；平板没打开就拍不了。
- 每天有用量上限（默认沫沫对话 80 次、妈妈对话 80 次、语音识别 150 次、配音 2 万字、「看看沫沫」60 次、在页面上点着问 100 次、在页面上找位置圈出来 200 次），在 `/etc/momo/momo.env` 里可以改。发照片和文件不限次数；单个文件最大 2 GB（`UPLOAD_MAX_MB` 可以改），超过 200 MB 的只存不读。
- 开了手机推送的话，推送的那一两句话会经过你选的推送服务（不含照片和录音）。
- 语音唤醒开着时，平板的麦克风一直开着，但只在平板上听有没有人喊伙伴的名字，听到名字之前什么都不发出去；屏幕顶上的「👂 喊「云笈」」就是提示。唤醒词模型和程序放在 `web/kws/`（sherpa-onnx，Apache-2.0，来源和改动见那里的 README）。
- 安静时间（默认 21:30–6:30）不发任务提醒，闹钟照常响。少女和宠物换成睡觉的样子；这时妈妈确认任务，平板只更新数字，不出声，宠物进化等到早上再宣布。

## 私有仓库

仓库设为私有后，服务器拉代码需要一个只读部署密钥：

```bash
ssh-keygen -t ed25519 -f /root/.ssh/momo_deploy -N "" -C momo-server
cat /root/.ssh/momo_deploy.pub
```

把输出的那一行加到 GitHub 仓库的 Settings → Deploy keys（不要勾选写权限），然后：

```bash
cat >> /root/.ssh/config <<'EOF'
Host github.com
  IdentityFile /root/.ssh/momo_deploy
EOF
cd /opt/momo-companion && git remote set-url origin git@github.com:willamxu881201-beep/momo-companion.git
```

## 开发

```bash
npm test                                   # 单元测试
PARENT_PASSWORD=test ARK_API_KEY=… npm start   # 本地运行，打开 http://127.0.0.1:8080/parent
```

改了页面以后，跑一下浏览器检查。每次会起一个临时的本地服务器（全新的数据库、随机的家长密码、不带任何 Key），用 Chromium 打开页面检查，截图和服务器日志放在 `tools/browser/out/`。第一次要装 Playwright：`npm install --no-save playwright && npx playwright install chromium`。

| 命令 | 检查什么 |
